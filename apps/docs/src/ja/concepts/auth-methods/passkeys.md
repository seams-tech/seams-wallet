# パスキー {#passkeys}

パスキーは、WebAuthnでユーザーの存在を確認します。
利用可能な場合は、疑似乱数関数（PRF）で保持者側の素材を導出します。

## モデル内の役割 {#role-in-the-model}

パスキーは、次の処理に使えます。

1. ローカルのユーザーの存在を証明する。
2. 保持者側の素材を導出またはアンロックする。
3. 期限切れや消費済みのウォレットセッション利用枠を、追加認証で更新する。
4. ポリシーが暗号学的要素を要求する場合に、機密性の高い操作を承認する。

パスキーは、アプリセッションに署名権限を与えません。
SDKは、結果を、他の認証方法と共通のレーン、ウォレットセッション利用枠、機能の許可、ポリシーのモデルへ変換します。
