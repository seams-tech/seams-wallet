# リンク済みデバイス {#linked-devices}

デバイス連携は、ユーザーが管理する別のデバイス用に、独立した署名レーンを作成します。

## フロー {#flow}

1. 新しいデバイスが、リンク用公開鍵を含むQR連携セッションを提示する。
2. 既存の所有者デバイスが、ユーザーを認証して権限を承認する。
3. 所有者側のWorkerが、リンクするデバイス用の独立した保持者シェアを作成する。
4. サーバーが、そのレーンに対応するサーバーシェアを作成する。
5. リンクするデバイスが、暗号化した保持者シェアのパッケージを受け取る。
6. 配送とウォレットアドレスの維持を確認してから、レーンを有効化する。

リンク済みデバイスは、独自の`laneId`、`laneShareEpoch`、保持者シェアのエンベロープ、権限ポリシー、取り消し状態、監査履歴を持ちます。

公開済みSDKは、所有者が管理するデバイスを、同じウォレットとそのホームリージョンに連携します。
選択した操作には、引き続きローカルのユーザー存在確認とサーバーの受付が必要です。
範囲を限定した委任条件によるデバイス・エージェントへの委任は、別の計画中機能です。

## アプリから連携する {#link-from-the-app}

新しいデバイスが、短時間だけ有効なQRペイロードを表示します。
認証済みの所有者デバイスが、連携フックを通じて読み取り、承認します。
