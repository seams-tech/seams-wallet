# 権限の委任 {#delegation}

権限の委任は、別のデバイス、エージェント、サービスへ、範囲を限定した署名レーンを与えます。
レーンには、独自の保持者シェアのパッケージ、サーバー側の受付状態、ポリシー、エポック、利用枠、有効期限、監査履歴があります。

同じウォレット鍵のレーンシェアを追加・更新する場合、ウォレットのアドレスは維持されます。
ウォレットの鍵交換は、別の操作です。
