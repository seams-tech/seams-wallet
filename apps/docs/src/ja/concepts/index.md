# 基本概念 {#concepts}

Seamsは、ユーザーやショッピングエージェントに継続利用するウォレットを提供するアプリ向けの、ウォレット・認証情報・ポリシーの基盤です。
誰が操作しているかを証明し、何を承認したかを型付きの操作意図として記録するために使います。
アプリは実行前にポリシーを適用し、実行後に監査の証跡を保持します。

```text
誰が操作しているかを証明する。
何を承認したかを証明する。
許可された操作だけを実行する。
```

ウォレット署名は、このモデルで承認済みの操作を実行する最初の手段です。
同じモデルを、決済経路、加盟店API、マーケットプレイスAPI、エージェント用ツール、権限を委任したデバイスの操作にも拡張します。

主な活用事例は、[プラットフォームのウォレット](/ja/use-cases/platform-wallets)、
[ショッピング用ウォレットアプリ](/ja/use-cases/shopping-wallet-apps)、[ショッピングエージェント](/ja/use-cases/ecommerce-agents)です。
Seamsは、Cloudflareにデプロイできる、セルフホスト可能なしきい値ウォレット基盤を提供します。

公開済みSDKは、ウォレットのライフサイクル、署名、所有者が選択するリージョン移動を提供します。
SDK 0.26.0では、任意の[VoiceID](/ja/concepts/auth-methods/voiceid)による登録、アンロック、送金承認を追加します。
エージェントへの権限発行とバーチャルカードは計画中の機能です。
これらの基本概念のページが存在しても、公開APIがリリース済みであることは意味しません。

公開済みの基準バージョンと更新時の境界は、[リリース状況](/ja/releases)を参照してください。
以下のレイヤー構成には、計画中の用途も含みます。公開済みの所有者向け認証方法は、パスキーとメールOTPです。

## システムのレイヤー {#system-layers}

| レイヤー           | 役割                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 証明               | パスキー、メールOTP、VoiceID、デバイスの証明、組織の証明、ウォレットの証明、設定済みの外部認証情報。                 |
| ポリシーと委任条件 | 署名済みの委任条件、型付き操作意図のダイジェスト、ポリシーのエポック、利用上限、有効期限、権限の取り消し、監査状態。 |
| 鍵の基盤           | 保持者のシェア、サーバーのシェア、Router A/B、SigningWorker、エクスポート、復元、権限の委任、ローテーション。        |
| 制御ゲートウェイ   | 資金、権限、在庫、APIの状態を変更する前に、許可、拒否、追加確認、人による承認を判定。                                |
| 実行アダプター     | ウォレット署名、決済、加盟店API、マーケットプレイス、エージェント用ツール、将来のデバイス操作。                      |

## ショッピングエージェントの要点 {#shopping-agent-short-version}

無制限の権限を渡さずに、エージェントが操作できるようにします。

エージェントが実行できる内容を定義し、署名済みの操作意図に紐づけます。
資金、在庫、権限が変わる前に、その条件を適用してください。
