# 委任条件 {#mandates}

委任条件は、権限を委任した実行者が行える内容を記録します。

```text
この対象は、このポリシーの下で、この期限まで、この利用枠内で、
この正確な操作意図の形式に対し、この種類のアクションを実行できる。
```

委任条件は、ユーザーの承認とエージェントの実行を結びます。
各委任条件に、明確な範囲と型付きフィールドを設けてください。取り消しと監査履歴にも対応させます。

## 主なフィールド {#core-fields}

| フィールド         | 役割                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| 対象               | ユーザー、組織のロール、ウォレット、デバイス、エージェント、サービス。 |
| 操作意図の形式     | 委任条件で承認できる、型付きのアクション群。                           |
| 制約               | 予算、加盟店、宛先、チェーン、市場、地理、時間、リスクの規則。         |
| ポリシーのエポック | 取り消しを考慮した判断に使う、バージョン付きのポリシー状態。           |
| 有効期限           | 委任権限の厳密な期限。                                                 |
| 監査情報           | 許可・拒否の内容を説明するための証跡。                                 |

## 例 {#examples}

- ショッピングエージェントが、承認済みの加盟店から500米ドル未満のジャケットを1着購入できる。
- 入札エージェントが、1つの出品に対して固定上限まで入札できる。
- 加盟店のサポートエージェントが、設定額まで返金できる。
- バックエンドサービスが、委任レーンで1つのウォレット操作意図を実行できる。

委任条件は、署名の制御を置き換えません。署名や別の実行アダプターが続行できる条件を制限します。
