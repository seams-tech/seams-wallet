# シール済み情報による更新 {#sealed-refresh}

シール済み情報による更新は、意図しないiframeやページの再読み込み後に、暗号化した署名素材を復元します。
平文の署名素材を、ブラウザーストレージに保存しません。

永続化するアセットは、ウォレットオリジンのIndexedDBに保存する、封印済みのセッション秘密情報です。
稼働中のサーバーの参加と、有効なサーバー側署名セッション状態がある場合だけ使えます。

## 規則 {#rules}

1. 更新レコードを、ウォレットiframeのオリジンに保存する。
2. 正確な素材の有効化とブラウザーセッションのマーカーへ、レコードを紐づける。
3. ロック、アカウント切り替え、取り消し、期限切れ、残り回数の消費時にレコードを削除する。
4. 復元するのは、トランザクションの署名機能だけとする。
5. エクスポート、リンク済みデバイスの作成、鍵のローテーション、委任エージェントの発行には、新たな操作承認を要求する。
