# ウォレットiframe {#wallet-iframe}

ウォレットiframeは、ブラウザーの分離境界です。アプリとは別のウォレットオリジンで実行します。
ウォレットUI、暗号化したローカルレコード、Worker、ウォレットオリジンのセッション状態を管理します。

## 境界 {#boundary}

| 境界                       | 役割                                                          |
| -------------------------- | ------------------------------------------------------------- |
| アプリオリジン             | SDKを呼び、アプリUIを表示し、公開操作の入力を渡す。           |
| ウォレットiframeのオリジン | ウォレットUI、IndexedDB、認証方法のフロー、Workerを管理する。 |
| ブラウザーWorker           | 使用中の保持者素材と、操作内の秘密状態を管理する。            |

アプリオリジンのJavaScriptは、公開結果と秘密を含まないフロー状態を受け取ります。
保持者シェア、PRF出力、メールOTP秘密素材、VoiceIDテンプレート、サーバーシェアは、アプリオリジンの外に留まります。
承認済みの鍵エクスポートは、ウォレットオリジンのビューアー内に素材を表示します。
`keys.exportKey`は、アプリへ操作結果を返します。秘密鍵は返しません。

公開済みSDKでは、WebAuthnの認証情報作成とアサーションをウォレットオリジンで実行します。
SDKは、iframeの権限をそのオリジンへ委譲します。アプリオリジンのWebAuthnへ切り替える経路はありません。
対応ブラウザーと、ウォレットオリジンに適合するRP IDを使ってください。

## 分離する理由 {#why-it-matters}

iframeは、ウォレットの権限をアプリページから独立させます。
アプリページが侵害されても、ウォレットオリジンの確認、ポリシー、認証要件を満たす必要があります。
署名レーンの参加前に、セッションの受付、リプレイ、署名利用枠の確認にも成功する必要があります。

## 境界を設定する {#configure-the-boundary}

Reactプロバイダーのマウント時に、ウォレットオリジンを明示します。
ウォレットサービスとSDKのパスは、その専用オリジンを基準に解決します。
