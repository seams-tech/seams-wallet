# リンク済みデバイス {#linked-devices}

連携処理の実装は、[ウォレットの高度な操作](/examples/advanced-wallet-operations)を参照してください。
リンクすると、新しいデバイスに独自の認証情報とレーンを作成します。
既存のデバイスが、その関係を承認します。既存デバイスの認証情報を転送することはありません。

## 処理の流れ {#flow-at-a-glance}

1. 新しいデバイスが、有効期間の短いセッションを開始し、QRコードを表示します。
2. 既存のデバイスがコードを読み取り、対象のウォレットとデバイスの要求を表示し、新たな認証で承認します。
3. 両方のデバイスが最終結果を確認し、新しいデバイスが自身の認証情報を保存します。

未完了のまま放置したセッションは失効させてください。UIをアンマウントしたら、ポーリングを停止します。
同じコードを繰り返し読み取っても、1回の読み取りと同じ結果になるようにしてください。
成功後は、デバイス名と作成日時を表示します。ユーザーが後から識別し、権限を取り消せるようにするためです。

リンク結果のすべての分岐を扱ってください。QRコードの内容は、公開可能な接続開始用データに限定します。
ウォレットの識別情報、セッション、鍵素材は、認証済みのウォレット境界内に保持してください。

プロトコルと権限の取り消しの詳細は、[リンク済みデバイス](/concepts/delegation/linked-devices)を参照してください。
