# 本番環境の確認事項 {#production-checklist}

ユーザーへ提供する実際のアセットと環境に対して、この一覧を確認してください。

## ビルドと識別情報 {#build-and-identity}

- [ ] ブラウザーSDK、Wallet Server、ホストするアセットが**0.25.0**を使う。復元CLIは**0.25.0**を使う。正確なパッケージバージョンとソースのリビジョンを記録する。
- [ ] アプリとウォレットホストが、どちらもiframeプロトコル16.0.0を使う。
- [ ] 開いたままの古いクライアントに更新案内が表示される。再読み込み後、現在のリリースで登録と署名が完了する。
- [ ] ドキュメント、アプリ、ウォレットランタイム、Worker、WASMが、未コミットの生成物なしでビルドできる。
- [ ] ネットワーク、プロジェクト環境、ウォレットオリジン、RP IDが対象レーンと一致する。

## セキュリティの境界 {#security-boundaries}

- [ ] 正確なオリジンの許可一覧、CSP、iframeメッセージ検証、リクエスト認証が有効である。
- [ ] ブラウザー設定に秘密情報が含まれない。
- [ ] 厳密な分離を保証する場合、Router A/Bの鍵管理ロールが、独立した認証情報と運用権限を持つ。
- [ ] チャレンジ、登録、復元、エクスポート、署名の各エンドポイントに、適切なレート制限とリプレイ対策がある。

## 製品のフロー {#product-flows}

- [ ] 対応ブラウザーで、登録、アンロック、最初の署名、キャンセル、復元、デバイス連携承認、エクスポート、取り消しが完了する。
- [ ] セッションの期限切れ、再試行可能な準備、通信失敗、ポリシーによる拒否、送信状態が不明な場合に、明確な対処方法がある。
- [ ] ウォレット画面で、モバイル、キーボード、スクリーンリーダー、動きを減らす設定、200%ズームの確認に合格する。

## 運用 {#operations}

- [ ] 監査イベントに、認証情報、鍵素材、OTP、トークンが含まれない。
- [ ] アラートが、秘密情報を公開せずに、対象レーンと境界を識別する。
- [ ] チームが、バックアップ、復元、切り戻し、秘密情報のローテーションを練習済みである。
- [ ] サポート担当が、公開エラーコードを現在の対処手順に対応付けられる。
- [ ] 有効な各ホームリージョンで、Worker/D1のバインディングとDurable Objectの配置を検証済みである。ルーティングやディレクトリーの停止時も、安全に失敗する。
- [ ] APACの登録と移動が`apac-se`を使う。実際のオブジェクト配置とデータベースのプライマリーを記録する。配置ヒントだけでは不十分である。
- [ ] Gatewayのマイグレーション`0081_registration_directory_publications.sql`を適用済みである。定期ハンドラーが保留中の登録通知を再開し、登録成功後にキューが解消する。
- [ ] Router、両Deriver、Signing Workerが、同じ非公開の割り当て契約を使う。期限切れで未使用のテナント承認は、更新前にフェンスで遮断する。
- [ ] 1つのウォレットが、デバイスや所在地が変わっても同じホームを保持する。複数のウォレットが、異なるホームで同時に動作できる。

## テナントルートのリリース {#tenant-root-release}

- [ ] 意図した更新受付ポリシーが、デプロイ済みリリースに含まれる。同じ操作の再試行は記録済み結果を再生する。1時間の待機期間中の別の手動更新は、プロバイダー処理前に失敗する。
- [ ] デプロイしたレーンで、新規ECDSA・Ed25519登録と署名が成功する。テナントルート更新後も、ウォレット識別情報が安定している。
- [ ] A/Bのバックアップと、管理型復元に必要な正規の識別・有効化メタデータを復元できる。各ロールの実行時認証情報は、自身の設定済みバックアップ鍵だけを利用できる。
- [ ] 管理型復元が必須の次世代更新を完了し、中断した有効化や廃止処理を記録済みチェックポイントから再開できる。
- [ ] 公開の安全性の説明が、実際の管理と鍵保持の境界に一致する。共有KMSバージョンは、テナント単位の消去を保証しない。

SDKの公開だけでは、特定環境で管理者向け復元や移行が有効であることを示しません。
提供前に、実際のダッシュボード、署名済みCLIバイナリー、復元素材の管理、移行先の復元経路を確認してください。
[復元機能の提供状況](/ja/deploy-and-operate/recovery-and-portability#availability)を参照してください。

## ドキュメントの公開 {#documentation-publication}

- [ ] インストール、実装例、リファレンス、運用の各ページが、[リリース状況](/ja/releases)と一致する。準備中の変更を明記する。
- [ ] 実装例のコンパイル、内部リンク、コードフェンスの分類、VitePressビルドが成功する。ブラウザーの証跡に、再現可能な一連の操作を含む。
- [ ] ステージングと本番が、意図したソースリビジョンを配信する。デプロイした`seams-wallet-docs-artifact.json`の記録を確認する。
- [ ] 深いリンク、検索、デスクトップ・モバイルのナビゲーション、ダークモード、図が動作する。正規URLとサイトマップが本番のドキュメントオリジンを使う。
- [ ] ステージングが`noindex`を要求する。切り戻し用に、以前のドキュメントアセットを保持する。
