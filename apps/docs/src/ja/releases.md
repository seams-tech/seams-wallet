# リリース 0.51.0

ブラウザーSDK、サーバーSDK、VoiceIDは **0.51.0** です。

- 所有者のNEARの費用の確認は、NEARが実際に請求する価格でガスを計算します。ブロックのガス価格を使いますが、ランタイムの`min_gas_purchase_price`より低くはしません。テストネットとメインネット(プロトコル88)では、この下限は`gas_price` RPCの値の10倍です。そのため100 Tgasの呼び出しには、手元に約0.1 NEARが必要です(大部分は後で払い戻されます)。これまでは`gas_price`の値だけを使ったため、確認はこのような呼び出しを通し、NEARが`NotEnoughBalance`で拒否していました。今はパスキーの画面の前にカードが閉じ、操作は`shortfall`付きの`not_submitted`で終わります。
- 費用の確認はRPCの呼び出しを1つ追加します(`EXPERIMENTAL_protocol_config`)。ほかの呼び出しと同時に行い、カードはこれを待ちません。
- `@seams/voiceid` 0.51.0と`@seams/wallet` 0.51.0を一緒にインストールしてください。VoiceIDのホストAPIはバージョン8のままです。

ウォレットのiframeプロトコルは **23.0.0**、ウォレット管理プロトコルは **5** のままです。
署名付きの復旧CLIは **0.29.0** のままです。このリリースにデータベースのマイグレーションはありません。
