# リリース 0.63.0

ブラウザーSDK、サーバーSDK、VoiceIDプラグイン、Speak-to-Signプラグインは **0.63.0** を使います。

- NEARカストディのキャッシュがないサイトやデバイスは、現在のクライアントシェアをRouterの再発行で受け取るようになりました。
  - パスキーのログイン、アカウントの同期、VoiceIDのアンロックがこれを行います。以前は、パスキーのログインがRouterの復旧を行い、状態エポックを進めて新しいマテリアルのアクティベーションを作っていました。VoiceIDのアンロックは「This site has no wallet keys on this device yet.」で失敗していました。
  - 再発行はマテリアルのアクティベーションと状態エポックを変えません。そのため、ローカルの権限とWallet Sessionの記録は変わらず、他のサイトのキャッシュも現在のままです。
  - ウォレットのEd25519のWallet Sessionであれば、VoiceIDのものも含め、どれでも再発行を許可できます。SigningWorkerは、Routerがクライアントパッケージを渡す前に、再発行されたシェアを開いて有効なシェアと照合します。SigningWorkerは何も保存しません。
  - キャッシュのないサイトでのEmail OTPには、引き続きリカバリーコードが必要です。この手順は今後のリリースでなくします。
- Gatewayは2つの新しいルート、`/router-ab/ed25519/yao/reissue/admit`と`/router-ab/ed25519/yao/reissue/execute`を提供します。`@seams/wallet-server/cloud-host`は、自分で組み立てるGatewayのために`handleRouterAbEd25519YaoReissueRequestV1`をエクスポートします。
- Routerのプロジェクトポリシーは`reissue`の作業種別を許可する必要があります。許可しないポリシーは再発行を拒否します。
- VoiceIDのカードが開いている間、Walletのフレームはスクロールバーを隠します。以前は、カードが開くときに、カードの右端にスクロールバーが約150ミリ秒表示されていました。
- Speak-to-SignのホストAPIはバージョン **8**、VoiceIDのホストAPIはバージョン **10** のままです。Speak-to-Signのベリファイアーは **0.5.2** のままです。OutLayerのバージョンキーは`96b79b518613a50538b060da2279c91e12b0619499c532c2708f61ddb790d7e5`です。
- Gateway、Router、2つのDeriver、SigningWorker、Walletホストを一緒にデプロイし、アプリを0.63.0に更新してください。0.62.0のRouterは再発行の操作を拒否します。0.62.0のWalletは0.63.0のサーバーでも動き続けます。キャッシュのないサイトでは、引き続き復旧を行います。
- 4つのパッケージをすべて0.63.0でインストールしてください。Speak-to-Signは引き続き実験的機能で、NEARテストネット専用です。実際の資金では使わないでください。

ウォレットのiframeプロトコルは **23.0.0**、ウォレット管理プロトコルは **5** のままです。
署名付きの復旧CLIは **0.29.0** のままです。このリリースはデータベースのマイグレーションを追加しません。
