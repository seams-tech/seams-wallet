# リリース 0.48.0

ブラウザーSDK、サーバーSDK、VoiceIDは **0.48.0** です。

- 所有者が `prepareOwnerTransaction` の承認または `cancelTransaction()` を確認すると、アプリのセッションからの送信と同じように、Walletのカードが取引のレシートに変わります。署名、送信済み、最終状態を表示し、トーストへの最小化と閉じる操作ができます。これまではカードが閉じていました。
- 所有者の送信がNEARに届かなかった場合、レシートはその理由を表示します。`unresolved` または `not_submitted` の結果は、`NotEnoughBalance` などのNEARの拒否を含むメッセージを表示します。
- VoiceIDの登録は、録音カードをすぐに開き、そのカードの中でVoiceIDをダウンロードします。回答の線の位置に角の丸いバーを、状態の行の位置にダウンロードのサイズを表示し、VoiceIDの準備ができると**Record sample 1**が使えるようになります。これまでは、カードの下に標準の進行状況バーを表示していました。
- ダウンロードに失敗した場合は、カードの中にエラーを表示し、録音ボタンの位置に**Retry loading**を表示します。アンロックとその他のVoiceIDの録音も同じ配置を使います。
- 独自の取引確認画面の後、ウォレットの承認画面は確認画面と同じ枠を保ちます。幅と左上の位置は変わらず、カードはその幅で表示されます。高さだけが変わるため、2つ目のモーダルが開いたようには見えなくなりました。
- 取引の詳細を開いて確認カードが枠より高くなった場合も、**Secured by seams**のフッターは表示されたままになり、詳細はその下でスクロールします。
- `@seams/voiceid` 0.48.0と`@seams/wallet` 0.48.0を一緒にインストールしてください。VoiceIDのホストAPIはバージョン8のままです。

ウォレットのiframeプロトコルは **23.0.0**、ウォレット管理プロトコルは **5** のままです。
署名付きの復旧CLIは **0.29.0** のままです。このリリースにデータベースのマイグレーションはありません。
