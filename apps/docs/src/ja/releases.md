# リリース 0.64.0

ブラウザーSDK、サーバーSDK、VoiceIDプラグイン、Speak-to-Signプラグインは **0.64.0** を使います。

- `seams.speakToSign.enroll`は、まだVoiceIDがないウォレットでVoiceIDを有効にします。そのVoiceID登録の3つのサンプルが検証者の録音にもなるため、所有者は文を2組ではなく1組だけ読みます。
  - Walletは、サンプルを検証者に送った後に自分のコピーを消去します。`activateAuthMethod`がアプリに音声を返すことはありません。
  - 所有者がVoiceIDを無効にした場合、`enroll`は引き続き理由`voiceid_unavailable`の`unavailable`を返します。`setAuthMethodEnabled`で再び有効にしてください。
  - `enroll`の前に`activateAuthMethod`を呼ぶアプリは引き続き動きますが、所有者は2回録音します。1回だけ録音するには、`enroll`だけを呼んでください。
- この登録の間、署名付きメッセージのWallet確認画面は、VoiceIDのカードの下に開かなくなりました。以前は、所有者が下にスクロールする必要がありました。
- VoiceIDのカードは、跳ねずに状態を変えます。
  - 変わる行は一緒にフェードアウトし、新しい行は1つずつフェードインします。ボタンとリンクはその場でフェードします。
  - 最初の登録カードは、同じ文のままアクティベーションのカードを引き継ぎます。以前は、カードが点滅し、別の文を表示していました。
  - モデルのダウンロードは、最初のバイトで表示されます。バーはダウンロードしたバイト数に従い、VoiceIDの準備中は満タンのままです。以前は、テキストが99%になってもバーは半分ほどで止まり、準備中は空で表示されていました。
  - Walletのフレームでは、短くなるカードはフレームのイージングに従うため、端が跳ねません。Walletの確認画面の後、カードは登場の動きなしで戻り、フレームが合うと行がフェードインします。
  - VoiceIDのアクティベーションの後、終わったカードはSpeak-to-Signのカードが代わるまで残ります。そのため、Walletがプラグインを読み込む間もフレームは空になりません。
  - Speak-to-Signのカードは、開くと音声検出の読み込みを始めます。以前は、ページで最初の録音のときに「Opening microphone…」が約3秒表示されていました。
- フレームより高いWalletの確認カードは、取引の詳細を1回の動きで開閉し、サイズが変わる間もスクロールの位置を保つようになりました。以前は、開閉が2段階で動き、Confirmボタンまでスクロールしたカードは先頭に戻っていました。
- 検証者のサービスが失敗したことを示すSpeak-to-Signの登録の拒否(`speaker_unavailable`など)は、カードに「The check is not available」と表示します。
- VoiceIDのホストAPIはバージョン **11**、Speak-to-SignのホストAPIはバージョン **9** です。Walletは別のバージョンのホストプラグインを拒否するため、`@seams/voiceid`と`@seams/speak-to-sign` 0.64.0を`@seams/wallet` 0.64.0と一緒にインストールしてください。Speak-to-Signのベリファイアーは **0.5.2** のままです。OutLayerのバージョンキーは`96b79b518613a50538b060da2279c91e12b0619499c532c2708f61ddb790d7e5`です。
- Walletホストを両方のプラグインと一緒にデプロイし、アプリを0.64.0に更新してください。このリリースでは、サーバーの変更は不要です。
- 4つのパッケージをすべて0.64.0でインストールしてください。Speak-to-Signは引き続き実験的機能で、NEARテストネット専用です。実際の資金では使わないでください。

ウォレットのiframeプロトコルは **23.0.0**、ウォレット管理プロトコルは **5** のままです。
署名付きの復旧CLIは **0.29.0** のままです。このリリースはデータベースのマイグレーションを追加しません。
