# リリース 0.49.0

ブラウザーSDK、サーバーSDK、VoiceIDは **0.49.0** です。

- 独自の取引確認画面の後、ウォレットの承認画面は確認画面の幅、左端、縦の中心を保ちます。高さだけが上下に同じだけ変わります。これまではカードが確認画面の上端を保っていたため、画面の中央にある短い確認画面の後、カードが画面の下の方に表示されていました。
- 独自の確認画面は、SDKがすでに持っているセッションと設定から開き、新しいセッションの読み取りは同時に行います。セッションが変わった場合は、これまでどおり確認画面をキャンセルします。これまでは、ウォレットのiframeからの2回の読み取りを順番に待っていました。
- **Continue to wallet**の後、所有者の承認はアプリのセッションを2回ではなく1回だけ読み取ります。ウォレットは接続の確認と同時に、NEARの費用の確認とトークンのメタデータの取得を始めるため、確認カードが早く表示されます。
- 確認画面の処理は、`seams:review:<step>` という名前のUser Timingの計測を記録します。アプリのページでは `review_open` と `continue_session_read`、ウォレットのiframeでは `owner_connection_check`、`owner_affordability`、`host_until_card_ready` を記録します。記録するのは時間だけです。
- `@seams/voiceid` 0.49.0と`@seams/wallet` 0.49.0を一緒にインストールしてください。VoiceIDのホストAPIはバージョン8のままです。

ウォレットのiframeプロトコルは **23.0.0**、ウォレット管理プロトコルは **5** のままです。
署名付きの復旧CLIは **0.29.0** のままです。このリリースにデータベースのマイグレーションはありません。
