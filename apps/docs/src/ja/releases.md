# リリース 0.50.0

ブラウザーSDK、サーバーSDK、VoiceIDは **0.50.0** です。

- **Continue to wallet**の後、所有者の承認はすぐにウォレットに届きます。ウォレットは承認のアプリのセッションを自分の新しい読み取りと比べ、同時に費用を確認します。セッションが変わった場合は、これまでどおり署名の前に承認を止めます。これまでは、承認はまずアプリのページのセッション読み取りを待っていました。ほかの確認画面付きのリクエストは、これまでどおりその読み取りを待ちます。
- ウォレットのカードは、NEARの費用の確認(`view_account`と`gas_price`)を待たなくなりました。確認の間もカードは取引を表示し、**Confirm**は確認の後で使えるようになります。アカウントが支払えない場合、カードはパスキーの画面の前に閉じ、操作は`shortfall`付きの`not_submitted`で終わります。何も署名しません。
- 独自の確認画面は、**Confirm**が準備中でも、カードの内容が確定した時点でウォレットのカードに切り替わります。
- `@seams/voiceid` 0.50.0と`@seams/wallet` 0.50.0を一緒にインストールしてください。VoiceIDのホストAPIはバージョン8のままです。

ウォレットのiframeプロトコルは **23.0.0**、ウォレット管理プロトコルは **5** のままです。
署名付きの復旧CLIは **0.29.0** のままです。このリリースにデータベースのマイグレーションはありません。
