# リリース 0.61.0

ブラウザーSDK、サーバーSDK、VoiceIDプラグイン、Speak-to-Signプラグインは **0.61.0** を使います。

- **実験的機能、NEARテストネット専用:** Speak-to-Signは、音声でプルリクエストのマージを承認します。
  - `seams.speakToSign.requestMergeApproval({ walletId, contract, repo, pullRequest, base, headCommit })`: 所有者は「merge pull request 42 into main」と話します。判定は、所有者が話さないリポジトリのSHA-256と20バイトのヘッドコミットも結び付けます。
  - 判定が承認すると、Walletコアはコントラクトの`approve_merge`呼び出しを1つ、デポジットなし、確認なしで署名します。Seamsの共同署名者は、そのリポジトリ、プルリクエスト、ベース、コミットに対するその呼び出しだけを受け入れます。
  - コントラクトが拒否する入力は、録音の前に`merge_not_valid`になります。
  - 検証者0.5.0以降が必要です。
- 音声による支払いを、より早く送信済みと表示します。
  - 音声で承認された通常の送金は、ブロックに含まれた時点で「送信済み」と表示します。結果は、約2ブロック後の実行結果を引き続き待ちます。ノート、評価、マージの承認はコントラクトの中で失敗することがあるため、引き続き実行結果を表示します。
  - 所有者が決まった文を読むとき、話した時間が文全体を満たした後は、1.5秒ではなく0.8秒の無音で録音を終えます。文の途中の間は、引き続き1.5秒です。VoiceIDのアンロックと登録は1.5秒のままです。
  - `sent`の結果の時間は、録音の終わりではなく、所有者が最後に話した言葉から始まるようになりました。そのため、`endOfSpeechToReceiptMs`は終わりの無音を含みます。
- 検証者0.5.1(`cdb46fea7fab5afbb855e373674c80a9cd77170beb594579da28d754009e7258`)は、話者と書き起こしのリクエストの実行中に、使用済み音声の印を書きます。そのため、各検証は約0.2秒短くなります。検証者が拒否した録音や、サービスの障害に当たった録音は使用済みになります。カードは試すたびに録音し直します。0.5.0のマージの承認も含みます。
- 共同署名者は、24時間より古いウォレットの判定の記録を削除し、音声の判定の拒否をそれぞれ理由とともにログに記録します。
- WalletホストはVoiceIDとSpeak-to-Signのプラグインを、ホストAPIのバージョンとWalletのアセットのバージョンを含むURLで読み込みます。そのため、デプロイの後もブラウザーがキャッシュの古いプラグインを使い続けることはありません。
- NEARのカストディのキャッシュがサーバーの鍵より古いサイトでは、パスキーのアンロックがキャッシュを更新するようになりました。古いキャッシュを見つけたVoiceIDのアンロックは、パスキーでのアンロックを1回求めます。別のサイトにある2つのアプリの間を移動するユーザーは、移動のたびにRouterの復旧を1回行うことがあります。このコストは今後のリリースでなくします。
- 受け取りと送信のパネルは、キーボードで操作できるスタイル付きの一覧から資産を選びます。
- Speak-to-SignのホストAPIはバージョン **8** です。VoiceIDのホストAPIはバージョン **10** のままです。Walletは、別のバージョンのホストプラグインを拒否します。
- `@seams/speak-to-sign`は、`seams-tech/speak-to-sign`リポジトリからリリースされるようになりました。
- 4つのパッケージをすべて0.61.0でインストールしてください。Speak-to-Signは引き続き実験的機能で、NEARテストネット専用です。実際の資金では使わないでください。

ウォレットのiframeプロトコルは **23.0.0**、ウォレット管理プロトコルは **5** のままです。
署名付きの復旧CLIは **0.29.0** のままです。このリリースはデータベースのマイグレーションを追加しません。
