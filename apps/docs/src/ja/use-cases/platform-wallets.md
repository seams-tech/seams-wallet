# プラットフォームのウォレット {#platform-wallets}

プラットフォームのウォレットは、アプリのアカウントに紐づく継続利用のウォレットです。
プラットフォームは、利用開始時にウォレットを作成します。
ユーザーは残高、資産、支払い、取引、送金、報酬、出金に繰り返し利用します。

```text
プラットフォームのアカウント
  -> 組み込みウォレット
  -> 残高または所有資産
  -> 繰り返し行う署名や支払い
  -> 復元、ポリシー、監査
```

## 適した用途 {#strong-fits}

- 購入者、販売者、残高、エスクロー、出金を扱うECマーケットプレイス。
- 取引・投資プラットフォーム。
- ゲーム・デジタル資産プラットフォーム。
- クリエイターやギグワーカー向けプラットフォーム。
- ステーブルコインの口座・送金アプリ。
- ロイヤルティ、報酬、ストアクレジットのネットワーク。
- エージェントによる商取引や自動購入のプラットフォーム。
- オンチェーン操作の費用を負担したり、操作を自動化したりするアプリ。

これらの製品は、ユーザーとの継続的な金銭関係を維持します。
残高、資産、出金、ポジション、報酬、委任した予算は、1回のセッションが終わっても存続します。

## Seamsが提供する機能 {#what-seams-provides}

- アプリのアカウントに紐づくウォレットの作成
- パスキーとアプリに組み込む認証
- 復元とデバイス連携
- しきい値署名とセルフホスト可能な基盤
- 費用を肩代わりする署名セッションと、繰り返し使える署名セッション
- 範囲と有効期限を限定し、取り消せる権限
- 操作意図に紐づく承認と監査の証跡
- 対応する方式でのウォレット管理権限のエクスポートまたは移管

## 導入の判断 {#qualification}

ユーザーがセッションをまたいで価値や資産を保持する場合に、プラットフォームのウォレットを使います。
繰り返す金銭操作やオンチェーン操作、上限を定めた自動化にも適しています。
1回の支払いを受け取る一般的な店舗は、購入者の既存ウォレットを使えます。別のウォレットを作成する必要はありません。

[組み込みウォレット](/ja/guides/embedded-wallets)と[ウォレットを作成](/ja/getting-started/create-wallet)から始めてください。
