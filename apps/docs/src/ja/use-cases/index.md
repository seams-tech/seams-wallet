# 活用事例 {#use-cases}

Seamsは、ユーザーやショッピングエージェントごとに、継続して使うウォレットが必要な製品向けの基盤です。
ウォレットはセッションをまたいで資金や資産を保持し、繰り返し行う操作に認証、復元、ポリシー制御、監査記録を提供します。

- [プラットフォームのウォレット](/ja/use-cases/platform-wallets)：マーケットプレイス、取引プラットフォーム、ゲーム、
  支払い・出金サービスなど、アカウントを使うアプリのユーザーにウォレットを提供します。
- [ショッピング用ウォレットアプリ](/ja/use-cases/shopping-wallet-apps)：ステーブルコインを保有し、直接送金、
  または任意のバーチャルカードで、独立した加盟店へ支払えるようにします。
- [ショッピングエージェント](/ja/use-cases/ecommerce-agents)：互いに独立したECストアで使う、範囲と有効期限を限定した購入権限をエージェントに委任します。

一度の支払いを受け取る店舗では、通常、購入者ごとにウォレットを作成する必要はありません。
購入者の既存ウォレットから送金を受け取ることができます。
製品内で残高、資産、支払いの受け取り、報酬、継続的な取引権限を維持する場合に、プラットフォームのウォレットが必要になります。

これらのページは、製品の方向性を説明します。機能をリリース済みと判断する前に、リンク先のガイドとAPIリファレンスを確認してください。
