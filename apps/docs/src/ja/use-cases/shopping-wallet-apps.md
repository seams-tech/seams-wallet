# ショッピング用ウォレットアプリ {#shopping-wallet-apps}

ショッピング用ウォレットは、ステーブルコインやその他の対応資産を保有する、iOSウォレットなどのアプリです。
所有者が独立した加盟店へ支払うために使います。

ウォレットは、加盟店が対応する決済手段を選べます。

```text
加盟店がステーブルコインに対応
  -> ウォレットから直接支払う

加盟店がカードのみに対応
  -> 任意のステーブルコイン連携バーチャルカードで支払う
```

バーチャルカードにより、既存のECサイトでも決済できます。ウォレット所有者が外部で支払うための認証情報です。
同じ店舗だけで使わせるためにカードを発行しても、その店舗にとっての利点は限られます。

## 製品側の責任 {#product-responsibilities}

- ウォレットの資金、カード用の準備金、保留中の利用枠、利用可能額を分けて表示する
- 対応する加盟店ではステーブルコインによる直接支払いを提供する
- カード決済を有効にする前に、上限を定めた準備金を割り当てる
- 利用承認、売上確定、承認取消、返金、凍結、終了の状態を表示する
- 手数料、為替レート、提供者の制限、準備金の解放時期を開示する
- カード番号（PAN）とセキュリティコード（CVV）を、提供者の安全なホストUI内で扱う
- 価値を二重計上せず、ウォレット、カード発行者、決済の証跡を照合する

バーチャルカードの発行には、カード会員の登録、不正利用、チャージバック、流動性、サポート、照合、規制への対応が伴います。
これは任意の機能です。外部の加盟店で支払う必要があるユーザーを持つ、適格なウォレット運営者に適しています。

バーチャルカードの発行は、製品の計画段階にあります。
公開済みWallet SDKは、カード発行やカードのライフサイクルを扱うAPIを提供しません。
利用可能なウォレット操作は、[SDKリファレンス](/ja/reference/)で確認してください。
